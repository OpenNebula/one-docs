# Wiki Sources

The files in `wiki/` are verbatim snapshots retrieved on 2026-09-29 from the OpenNebula website Wiki. `wiki/manifest.json` records original URLs, retrieval date, and SHA-256 identities. Upstream Git revisions were not obtained; these are content-addressed snapshots, not claims about a particular Wiki commit. The Wiki remains authoritative; do not independently edit its saved rules.

Read by topic:

- [Document Type](wiki/Document-Type.md): intended audience and purpose.
- [Document Structure](wiki/Document-Structure.md): frontmatter, heading levels, and structure by document type.
- [Writing Style](wiki/Writing-Style.md): tone, voice, and instructional phrasing; includes explicit exceptions.
- [Capitalization](wiki/Capitalization.md): headings and prose terminology.
- [Spelling](wiki/Spelling.md): US English, punctuation, emphasis, and literal formatting.
- [Links and References](wiki/Links-and-References.md): internal relref and external links.
- [Images](wiki/Images.md): assets, shortcodes, and preferred formats.
- [Code and Command Line](wiki/Code-and-Command-Line.md): fenced blocks, prompts, output, and placeholders.
- [Branding](wiki/Branding.md): product names versus command names.
- [Home](wiki/Home.md): overview and source navigation, not a verified release/version map.

Known source limitations: Home contains misspelled/misdirected Spelling links; the actual Spelling page was fetched directly. Images contains differently spaced shortcode examples; do not prescribe unverified syntax from an example. Writing Style includes linguistic claims that should not be presented as general facts; preserve its stated recommendation strength. No precedence between conflicting Wiki pages has been established. Historical releases may require historical style guidance; disclose this when reviewing them with this snapshot.

To refresh deliberately, retrieve the chosen pages, review source changes, and update manifest hashes and retrieval dates together. Do not interpret the fetch date as an upstream revision.
