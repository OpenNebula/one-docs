# Legacy CE ISO Recipes

These recipes reproduce the network wizard and vLLM marketplace screenshots from
the former Community Edition ISO guide. That guide was removed in the Getting
Started restructure (`ef97801c`); its old screenshot assets are also absent.

The recipes are retained unchanged as debugging references, not as runnable
manifests for the current documentation. The active group uses
`../ee-iso-network.json` for the Enterprise Edition ISO guide at
`content/solutions/engineering_blueprints/ee_poc/ee_poc_iso.md`.

Do not map the vLLM or GPU screenshots onto the EE guide: it does not contain
those steps. Running a legacy workflow requires an isolated checkout with the
matching documentation/assets and its own manifest/output directory.
