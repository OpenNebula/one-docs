OpenNebula is a powerful, but easy-to-use, open source platform to build and manage enterprise clouds and virtualized Data Centers. This Getting Started section of the OpenNebula documentation helps you take your first steps in exploring the OpenNebula ecosystem. 

## Try OpenNebula with miniONE

Taking your first steps in OpenNebula is easy using the automated rapid-deployment tool **miniONE**. miniONE is an optimized script that installs the fundamental components of an OpenNebula cloud quickly, such that a basic cloud architecture is established with a **Front-end** or **control plane** to manage the cloud along with a single **hypervisor node** to handle workloads.

If this is your first time trying OpenNebula, the best place to start is with the miniONE installation and evaluation guides:

* [Deploy OpenNebula On-premises with miniONE]({{% relref "getting_started/install_opennebula/evaluation/deploy_opennebula_onprem_with_minione/" %}})
* [Deploy OpenNebula on AWS with miniONE]({{% relref "getting_started/install_opennebula/evaluation/deploy_opennebula_on_aws/" %}})
* [Validate your miniONE Deployment]({{% relref "getting_started/install_opennebula/evaluation/validate_the_environment/" %}})
* [Try Deploying a Kubernetes Cluster with OneKS]({{% relref "getting_started/install_opennebula/evaluation/oneks_quickstart/" %}})
