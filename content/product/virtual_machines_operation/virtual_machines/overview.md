<!--# Overview -->

Define a Virtual Machine in a VM Template, then instantiate the Template to create a VM instance. Use the following guides for each task:

- [Virtual Machine Templates]({{% relref "product/virtual_machines_operation/virtual_machines/vm_templates.md" %}}): Define reusable VM configurations.
- [Managing Virtual Machine Instances]({{% relref "product/virtual_machines_operation/virtual_machines/vm_instances.md" %}}): Instantiate Templates, manage the VM lifecycle, schedule actions, and control permissions.
- [Managing Virtual Machine Resources and Storage]({{% relref "product/virtual_machines_operation/virtual_machines/vm_resources.md" %}}): Manage VM resources, disks, snapshots, and datastore migration.
- [Accessing Virtual Machines]({{% relref "product/virtual_machines_operation/virtual_machines/vm_access.md" %}}): Connect to VM consoles and desktops, and run guest commands.
- [Virtual Machine Images]({{% relref "product/virtual_machines_operation/virtual_machines/images.md" %}}): Manage the disk Images used by VM Templates and instances.

## Hypervisor Compatibility

Check each operation's requirements and the relevant hypervisor driver for support and limitations.
