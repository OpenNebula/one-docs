[Open OnDemand](https://openondemand.org/) is a web portal for HPC resources. Users sign in from a browser and get a file browser, a shell, batch job submission and interactive applications such as JupyterLab, RStudio and VS Code. The Open OnDemand Service runs it on OpenNebula as a OneFlow service, with a portal, a shared home directory and a pool of compute VMs that grows and shrinks with the number of open sessions.
