The OneKS application catalogue contains validated Helm-based applications that can be installed and managed as part of a K8s Cluster. 

You can manage applications through Sunstone or the CLI. See the [K8s Cluster Lifecycle Management Guide]({{% relref "platform_services/oneks/management/k8s_cluster_lifecycle_management/#managing-applications" %}}) for details. To add new applications or reusable components to the catalogue, see [Creating Custom Applications]({{% relref "platform_services/oneks/references/creating_custom_applications/" %}}).
